# Quote fonts

Noto Serif SC, weights 400 and 500, provided by Google Fonts under the SIL Open Font License (see OFL.txt). These WOFF2 subsets cover the character names, epithets, quotes and taglines in data/site-data.js, plus the quote punctuation and empty quote text.

The homepage quote area uses these local fonts so external font availability and installed system fonts do not change its appearance. When changing this text, run `python tools/update_quote_fonts.py` to regenerate both subsets.

Source: https://fonts.google.com/noto/specimen/Noto+Serif+SC
