## 图片方向

`tools/tex_to_png.py` 根据 KTEX 头读取像素格式、mipmap 数量、首层大小和行跨度。
支持本包使用的 DXT5、RGBA，以及 DXT1。解码后统一上下翻转一次，适配浏览器坐标原点。
DXT5 的透明度独立解码；DXT1 的透明色保留透明度。

批量更新命令：

```powershell
python -m pip install Pillow
python tools/sync_mod_images.py ../bighead.zip
python tools/check_textures.py
```

工具根据 `data/site-data.js` 中实际引用的路径导出物品、节气、机制、地点和外观图片，
共 128 张。角色立绘、海报和 UI 装饰 PNG 为原有独立素材，不做上下翻转。
貔貅「玉桂狗」的注册项没有配套的独立背包贴图，使用召唤物品图标，并在条目中说明。
不将动画 ZIP 或默认占位大头像当成角色立绘导入。
