资料源为 `bighead.zip`，包内 `modinfo.lua` 的版本号为 `4.8`。
2026-10-30 是本站同步日期，不作为模组官方发布日期。
页面「更新」只展示模组游戏内容，不展示本文档所述的 Wiki 维护工作。

## 游戏更新记录依据

对照 `.scratch/bighead/modinfo.lua`（v4.4）与
`.scratch/bighead-v4.8/bighead/modinfo.lua`（v4.8），配置项从2项增加至12项。

岩浆泡澡回复、貔貅移速、四季内容开关、如意捕捉四季灵开关、每日投喂开关、嫁接上限。

v4.4 记录为该版本已包含的角色与四季玩法概览，不表示这些玩法首次加入于 v4.4。
来源为旧版 `modinfo.lua` 与 `strings.lua`。本地包未附作者版本更新日志，

## 图片方向

`tools/tex_to_png.py` 根据 KTEX 头读取像素格式、mipmap 数量、首层大小和行跨度。
支持本包使用的 DXT5、RGBA，以及 DXT1。解码后统一上下翻转一次，适配浏览器坐标原点。
DXT5 的透明度独立解码；DXT1 的透明色保留透明度。

批量更新命令：

```powershell
python -m pip install Pillow
python tools/sync_mod_images.py ../bighead.zip
python tools/check_textures.py
```

工具根据 `data/site-data.js` 中实际引用的路径导出物品、节气、机制、地点和外观图片，
共 131 张（包括补录的美味罐头、牛肉、羊肉）。角色立绘、海报和 UI 装饰 PNG 为原有独立素材，不做上下翻转。
貔貅「玉桂狗」的注册项没有配套的独立背包贴图，使用召唤物品图标，并在条目中说明。
不将动画 ZIP 或默认占位大头像当成角色立绘导入。

## 落地展示图

`assets/img/displays/` 中的 127 张透明 PNG 由 DST Mod Tool 1.1.13 的官方 Lua 接口
渲染模组动画 ZIP，覆盖全部物品、节气与外观，并供相关机制、青玄阁外观复用。
冬季10级与普通冬季共用同一落地形态；貔貅「玉桂狗」有独立的实际外观展示图。
前室、厅堂和左右两间卧房分别用对应的原始墙面与地板合成预览，标注「内景预览」，
名称旁继续使用建筑小图标。墙面依次来自房间代码指定的 `bighead_wall`、
`bighead_wall1`、`bighead_wall2`、`bighead_wall3`，地板分别使用同编号的
`bighead_floor`、`bighead_floor1`、`bighead_floor2`、`bighead_floor3`。
不放大地图 icon 充当内景。

每个资源的动画 bank、build、动作、帧号、原始尺寸、透明裁边和条目映射均记录在
`data/display-assets.json`。选择实际落地/待机动作：锅用 `idle_ground`，草莓丛用
`idle_full`，春朝亭用 `honey3`。何三宝、伞与元神借用游戏本体的对应动画 bank，
保持模组自身 build。没有拼贴纹理图集或放大背包图标。

渲染采用原生 `scale=1`，只裁去透明边距并补8像素留白；**不翻转、不放大**。
网页使用 `object-fit: scale-down`，较小的原画不会超出原始分辨率显示。
原 `image` 字段继续用于名称前与配方小图标，新增 `display_image` 用于卡片和详情。

先在 DST Mod Tool 中切换到空文档，再执行（把路径替换为本机位置）：

```powershell
python tools/export_mod_displays.py --tool "C:/tools/dst-app.exe" --mod "../bighead.zip" --game-anim "D:/Steam/steamapps/common/Don't Starve Together/data/anim"
```

导出脚本分批导入，每批 PNG 导出完后撤销该次导入，结束时工作区仍为空；不保存或重置
已有文档。若开始时文档非空，脚本直接退出。也可用 `--native-dir <原生PNG目录>`
复用已导出的图，只执行透明裁边与留白。

室内墙景超过工具单次 4096px 画布限制，使用四块原生分辨率画布导出并无缝合并，
裁去透明边距后缩小至1600px长边并补8px透明留白。地板由工具导出原生PNG，保留原图
上下方向，将其四角投影到墙脚所在的梯形地面，再将完整墙面叠到地板前方，接缝略作重叠，
避免白缝。前室为太极石砖、厅堂为星盘地砖、左卧房为灰木地板、右卧房使用独立纹理。
来源、尺寸及各房间地板的四角坐标记录在 `data/terrain-previews.json`；这些是原始素材
合成的内景预览，不是游戏实拍截图。

前室预览另外叠入 `bighead_men.zip` 的 `men1` 第1帧，使用墙景的缩小比例，
在后墙中央显示鎏金太极铃。其素材、位置与尺寸记录在前室的 `furnishings` 中；
条目 `scene_hotspots` 使用相对坐标覆盖铃铛，鼠标点击、触摸或键盘激活会打开厅堂详情。

厅堂另外叠入同一动画包的 `yizi`（太极莲尊）和两份 `men2`（引霄灵藤）第1帧。
先使用墙景的缩小比例，根据房间生成代码中相对中心的坐标，将各自的动画原点投影到
同一地面平面；右侧灵藤按代码中的 `eastside` 水平镜像。灵藤在剖面预览中对齐外侧楼梯，
图像偏移单列为 `preview_offset`，不将其冒充模组坐标。

前室与厅堂的前方补入 `bighead_door_exit.zip` 的 `idle` 出口台阶；左、右卧房分别补入
`bighead_men.zip` 的 `men3`（鎏角青玄门）和 `men4`（银翘古木门）。门与台阶使用各自的
实际生成坐标与原始朝向。剖面预览在墙景缩小比例上另作等比校准：灵藤1.5倍、台阶2.6倍、

校准单列为 `preview_scale`，仅用于合成展示，不代表游戏中的实体缩放。
清单记录素材、房间坐标、镜像及最终图像边界；
两扇卧房门底边对齐前侧墙口的地面，厅堂出口台阶跨过地板前沿；台阶下方自动增加透明

导出脚本根据最终边界同步条目 `scene_hotspots`，避免图像移位后点击区域停在旧位置。

原始比例居中适配；热点相对于实际图像区域定位，不包含画框留白。编号、路线与出口按钮
预留统一高度，切换房间保持位置不变。电脑端右侧说明框与左侧画框等高，长内容在框内滚动；
手机端说明自然展开。
每张预览下方按实际连接展示从屋外到当前房间的完整入阁路线，当前房间单独标识，
前序节点可点击返回；直接相连的门和台阶仍保留操作按钮。切换房间不主动滚动页面。

## 角色立绘与游戏模型联动

```powershell
python tools/export_character_models.py --tool "C:/Users/huan/Downloads/dst-app.exe" --mod "../bighead.zip" --game-anim "D:/Steam/steamapps/common/Don't Starve Together/data/anim"
```

导出器要求工具文档为空；导出完成后撤销本次资源导入，恢复原来的空文档。
