# 数据结构参考

`data/site-data.js` 里每个字段的完整说明。写内容时当字典查。

---

## 顶层结构

| 键 | 类型 | 必填 | 作用 |
|---|---|---|---|
| `meta` | object | ✅ | 站点标题、作者、版本、外链、页脚 |
| `categories` | array | ✅ | 物品分类表 |
| `characters` | array | ✅ | 角色（**必须且只能 2 个**） |
| `items` | array | ✅ | 物品 |
| `mechanics` | array | ✅ | 机制 |
| `terrains` | array | ✅ | 地形 |
| `changelog` | array | ✅ | 更新日志 |
| `seasons` | array | ⬜ | 季节（走「扩展字段」自动发现） |
| `posters` | array | ⬜ | 首页海报轮播 |
| `sections` | array | ✅ | 分区定义，决定导航与页面块 |
| `relations` | object | ⬜ | 手动覆盖 `id → 展示名` 映射 |

> **扩展字段**：除了上表的固定键，任何**新增的数组字段**都会被 `assets/js/data.js` 自动发现，加入搜索索引和 `[[双链]]` 名称表。`seasons` 就是这么工作的。

---

## `meta`

| 字段 | 类型 | 说明 |
|---|---|---|
| `site_title` | string | 站点主标题，同时作为浏览器标题 |
| `subtitle_latin` | string | 首页主视觉下方副标题，留空则不显示 |
| `author` | string | 作者名，显示在首页元信息与页脚 |
| `version` | string | 版本号，显示在首页元信息 |
| `workshop_url` | string | 创意工坊链接，首页与页脚都会用 |
| `manifesto` | string | 站点宣言，页脚展示 |
| `links` | array | `[{ label, url }]`，页脚外链列表 |
| `copyright` | string | 页脚版权行 |

---

## `categories`

```js
{ "id": "weapon", "name": "武器" }
```

| 字段 | 说明 |
|---|---|
| `id` | 被 `items[].category` 引用 |
| `name` | 筛选面板与卡片上显示的中文名 |

当前已有：`weapon` 武器、`tool` 工具、`material` 材料、`structure` 建筑、`food` 食物、`crop` 作物、`misc` 其他。

新增分类只需加数组元素，筛选按钮自动出现。

---

## `characters`（角色）

⚠️ **硬约束**：`assets/js/data.js` 里把两个角色 id 写死为 `pangtouyu`（左）和 `gaojiaoniao`（右）。**改 id 会导致首页塌掉**。超过 2 个角色不会被渲染。

```js
{
  "id": "pangtouyu",
  "side": "zuo",                       // zuo=左 / you=右
  "name": "胖头鱼",
  "epithet": "角色外号",                // 可被全局搜索命中
  "portrait": "assets/img/characters/pangtouyu_head.png",
  "stats": { "hp": 150, "san": 200, "hunger": 150 },
  "setting": ["设定条目1", "设定条目2"],
  "exclusive_intro": ["专属介绍第一段", "……"]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | **必须是 `pangtouyu` / `gaojiaoniao`** |
| `side` | string | `zuo` 显示在左，`you` 显示在右 |
| `name` | string | 角色名，参与搜索与双链 |
| `epithet` | string | 外号/称号，参与搜索 |
| `portrait` | string | 立绘路径 |
| `stats.hp` / `san` / `hunger` | number | **必须是数字**，显示为 `HP 150 / SAN 200 / HUNGER 150` |
| `setting` | string[] | 「设定」按钮点开后的逐条内容 |
| `exclusive_intro` | string[] | 「专属」按钮点开后的逐段内容 |

> 点击角色卡片不是在弹窗里打开，而是在首页弹出角色浮层（`assets/js/char-popup.js`）。

## `items`（物品）

```js
{
  "id": "item_inkstone",
  "name": "占位物品1",
  "category": "tool",
  "owner": "pangtouyu",
  "image": "assets/img/items/testitem.png",
  "summary": "简介",
  "recipe": "[res_stone] ×1  [res_charcoal] ×1",
  "tech": "所需科技",
  "detail_blocks": [ ... ],
  "related": ["pangtouyu", "item_brush"],
  "tags": ["标签1", "标签2"]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✅ | 唯一标识 |
| `name` | string | ✅ | 显示名，参与搜索与双链 |
| `category` | string | ✅ | 必须是 `categories` 里的 id，否则显示为「其他」 |
| `owner` | string | ✅ | `pangtouyu` / `gaojiaoniao` / `common` |
| `image` | string | ✅ | 图标路径 |
| `summary` | string | ⬜ | 卡片摘要；支持 `[[双链]]` |
| `recipe` | string | ⬜ | 配方，`[id]` 渲染成素材图标；空字符串表示无配方 |
| `tech` | string | ⬜ | 所需科技，纯展示文本 |
| `detail_blocks` | array | ⬜ | 详情图文块，见下 |
| `related` | string[] | ⬜ | 关联条目 **id** 列表 |
| `tags` | string[] | ⬜ | 标签，参与搜索 |

---

## `detail_blocks`（详情图文块）

三种用法：

```js
// 段落
{ "type": "text", "content": "支持 [[双链]] 的正文。" }

// 图片
{ "type": "image", "src": "assets/img/items/xxx.png", "caption": "图片说明" }

// 省略 type 时按段落处理（content 里写文字）
{ "content": "也可以不写 type" }
```

| 字段 | 说明 |
|---|---|
| `type` | `"text"` 或 `"image"`，**只支持这两种** |
| `content` | `text` 类型的正文，支持 `[[双链]]` |
| `src` | `image` 类型的图片路径 |
| `caption` | `image` 类型的说明文字 |

## `seasons`（季节）

走扩展字段机制，字段与 `terrains` 一致，但用 `name`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一标识 |
| `name` | string | 季节名 |
| `image` | string | 图标 |
| `summary` | string | 简介 |
| `related` | string[] | 关联 id |
| `detail_blocks` | array | 同物品 |

> 注意：`sections` 里季节分区的 `rootId` 写的是 `season-root`（单数），这是历史命名，不影响功能。

## `changelog`（更新日志）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一标识 |
| `title` | string | 更新标题 |
| `version` | string | 版本号，显示在时间轴左侧 |
| `date` | string | **必须 `YYYY-MM-DD`** |
| `image` | string | 封面图（卡片里不一定显示） |
| `related` | string[] | 关联 id |
| `changes` | string[] | 逐条变更内容，支持 `[[双链]]` |

数组**第一条**会被标上「新」印章。更新日志**不弹详情窗**。

|---|---|

| `caption` | 同时作为 `alt` 文本与加载失败时的显示文字 |

## `sections`（分区）

```js
{
  "id": "items",
  "title": "物品",
  "themeClass": "section--paper",
  "rootId": "items-root",
  "splitHeader": true,
  "filterButton": true
}
```

| 字段 | 说明 |
|---|---|
| `id` | 必须与数据里某个数组键同名 |
| `title` | 导航与标题文字 |
| `themeClass` | `section--paper`（白）/ `section--ink`（黑） |
| `rootId` | 内容容器 id。**`items` 必须 `items-root`，`changelog` 必须 `changelog-root`**（render.js 写死） |
| `splitHeader` | 仅物品区：标题栏与主体分离 |
| `filterButton` | 仅物品区：显示筛选按钮 |
| `progress` | 可选：显示横向滚动进度条 |

---

## `relations`（手动名称映射）

默认为空 `{}`。`id → 展示名` 的映射由程序自动从 `name` / `title` 生成；如果你想让某条目在双链里显示成**另一个名字**，在这里手动指定，手动值优先。

```js
"relations": {
  "item_inkstone": "墨石（别称：玄石）"
}
```

## 三个魔法语法速查

| 语法 | 位置 | 说明 |
|---|---|---|
| `[[名称]]` | `summary` / `changes` / `setting` / `exclusive_intro` / `detail_blocks[].content` | 站内跳转，名称需与某条目的 `name` 或 `title` **完全一致** |
| `[id]` | `recipe` | 渲染为「图标 + 名字」 |
| `?editor=1` | 浏览器地址栏 | 打开校阅面板 |

---

## 路由（URL hash）

站内状态全在 hash 里，可以直接分享链接：

| 链接 | 效果 |
|---|---|
| `#items` | 跳到物品分区 |
| `#items/item_inkstone` | 打开某物品详情弹窗 |
| `#items?cat=weapon,tool` | 只看武器和工具 |
| `#items?owner=gaojiaoniao` | 只看高脚鸟的 |
| `#items?q=墨石` | 带搜索词 |
| `#序` | 序章 |

## 已知限制汇总

| 限制 | 位置 | 说明 |
|---|---|---|
| 角色 id 硬编码 | `assets/js/data.js` `normalizeCharacters` | 只认 `pangtouyu` / `gaojiaoniao`，且只渲染 2 个 |
| 归属标签硬编码 | `assets/js/data.js` `App.config.ownerLabels` | 新角色不会进筛选 |
| 容器 id 硬编码 | `assets/js/render.js` `renderItems` / `renderChangelog` | `items-root` / `changelog-root` |
| 搜索类型标签只覆盖 5 种 | `assets/js/filter.js` `getSearchResults` | `seasons` 等扩展分区的条目没有类型标签 |
| 弹窗 eyebrow 只覆盖 5 种 | `assets/js/modal.js` `genericView` | 扩展分区条目弹窗顶部小字为空 |
| 扩展分区弹窗 hash 归到 intro | `assets/js/modal.js` `sectionForEntry` | 功能正常，只是 hash 里 section 变成 `intro` |
| 首页 UI 装饰字硬编码 | `index.html` | `assets/img/ui/*.png` 四个文件不能改名 |
| 角色立绘文件名硬编码在数据里 | `site-data.js` `characters[].portrait` | 走数据，改数据即可 |
