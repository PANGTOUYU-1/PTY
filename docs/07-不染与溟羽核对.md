## 图片

通过 DST Mod Tool 1.1.13 原生 Lua API 导出模组 `anim/bb_gaojiaoniao_my.zip`，动画依赖游戏原版 `shadow_thrall_wings.zip`；bank 为 `shadow_thrall_wings`，build 为 `bb_gaojiaoniao_my`，动作 `idle_down` 第1帧，原生缩放1。工具文档在导出后通过撤销恢复为空白，未保存用户文档。

原图1024×595，透明边裁切范围 `[73, 9, 951, 570]`；仅裁透明边并补8像素留白，得到894×577的展示图。没有独立背包图标，因此另从展示图等比生成96×62缩略图。展示图保持原生比例和大小；缩略图规则记录在 `data/display-assets.json` 的 `thumbnail_*` 字段，可由 `tools/export_mod_displays.py` 重建。

当前清单126张展示图，收录67项物品与伙伴；模组KTEX小图标仍为129张，原版素材图标仍为77项。
